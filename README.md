## FinanzApp - App propia de Finanzas personales (Estilo Dashboard)
Aplicación web para registrar ingresos y gastos y ver cómo van las cuentas del mes, teniendo en cuenta el balance, gastos por categoría y evolución a lo largo del mes.

**Demo:**

## Que puede hacer:
- Alta y baja de movimientos (monto, categoría, fecha, descripción).
- Tarjetas con balance, ingresos y gastos.
- Gráfico torta con los gastos por categoría.
- Gráfico de barras con los últimos 6 meses.
- Filtros por mes y por categoría.
- Los datos se guardan en el navegador.
- Botón para cargar datos de ejemplo y probar la app rápido.
